# Giáo án thăng cấp đai màu

- `Giao-an-CLB-Viet-An-Cap-10-den-Cap-1.docx` — giáo án dạng **form ô** (bố cục giống mẫu giáo án): mỗi tuần 1 trang.
- `Mau-form-giao-an-Taekwondo-Viet-An.docx` — mẫu trống 1 trang (photocopy / điền tay).
- `build_giao_an.py` — dữ liệu nội dung từng cấp/tuần.
- `build_giao_an_form.py` — dựng file Word theo form theme Taekwondo Việt An.

Chạy lại form:

```bash
python3 docs/build_giao_an_form.py
```

Nội dung thi bám QĐ 152/2025/QĐ-VTF. Lịch Việt An: 3 buổi × 90 phút, khởi động chung rồi chia trạm.
