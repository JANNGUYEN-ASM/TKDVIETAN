# Giáo án thăng cấp đai màu

- `Giao-an-CLB-Viet-An-Cap-10-den-Cap-1.docx` — giáo án vận hành CLB (HLV + phụ huynh), Word để chỉnh sửa.
- `build_giao_an.py` — script tạo lại file Word nếu cần regenerate.

Nội dung thi bám QĐ 152/2025/QĐ-VTF. Cách chia phút/tuần là giáo án Việt An (3 buổi × 90 phút, khởi động chung rồi chia trạm).
